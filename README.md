# Arkipelago PopTracker

> A PopTracker pack for the **ARK: Survival Evolved** [Archipelago](https://archipelago.gg) integration.
> 
> 🔗 **AP World:** Get the corresponding `.apworld` from the [ARK Archipelago Repository](https://github.com/Jbaker16163/Ark-Survival-Archipelago).

---

## 📦 Installation

1. Download and install the PopTracker application from [poptracker.github.io](https://poptracker.github.io/).
2. Download the latest release `.zip` of this pack.
3. Place the `.zip` file into your PopTracker `packs` folder.
4. Launch PopTracker and select **Arkipelago** from the pack list.

## ⚠️ Known Issues

* **Tame Logic:** Incomplete — logic is still being actively refined in the `.apworld`.
* **Explorer Note Logic:** Incomplete — pending logic implementation in the `.apworld`.
* **Boss Logic:** Minimal coverage — Artifact logic exists, but there is no logic for combatting bosses.

> **Autotracking is currently UNTESTED.** If you run into any bugs, missing checks, or unexpected behavior, please open an issue or let me know!
